## Tu Tarea

Coordina los agentes `desarrollador-editorial` y `desarrollador-fullstack-backend` para crear una integración optimizada entre el módulo editorial y el sistema backend.

### Objetivos de integración:

1. **Editorial APIs**: APIs backend específicamente diseñadas para funcionalidades editoriales
2. **Processing Optimization**: Optimización de procesamiento de formatos EPUB, PDF, MOBI
3. **Quality Preservation**: Garantizar que optimizaciones no afecten calidad editorial
4. **Scalable Architecture**: Backend que soporte operaciones editoriales a escala
5. **User Configuration Respect**: Preservar todas las configuraciones editoriales del usuario

### Áreas de integración:

#### Backend Editorial Services
- APIs para configuración de metadatos editoriales
- Servicios de procesamiento de formatos (EPUB, PDF, MOBI)
- Sistema de gestión de assets editoriales (portadas, imágenes)
- APIs de validación de compliance editorial
- Sistema de descargas seguras con tokens temporales

#### Claude AI Integration para Editorial
- Generación inteligente de elementos editoriales (copyright, biografías)
- Optimización de prompts para contenido editorial
- Procesamiento batch para múltiples libros
- Quality assurance automática para contenido generado

#### Database Optimization para Editorial
- Esquemas optimizados para metadatos editoriales complejos
- Índices para búsquedas de contenido editorial
- Optimización de consultas para procesamiento de libros
- Backup strategies para contenido editorial

#### Performance Optimization
- Caching inteligente para assets editoriales
- Procesamiento asíncrono de formatos pesados
- Optimización de transferencia de archivos
- Compresión optimizada para distribución

### Funcionalidades específicas:

1. **Metadata Management**: Sistema completo de gestión de metadatos Dublin Core
2. **Format Processing**: Conversión optimizada entre formatos editoriales
3. **Asset Pipeline**: Pipeline optimizado para generación y gestión de assets
4. **Distribution Ready**: APIs para preparar libros para distribución
5. **Quality Validation**: Validación automática de compliance editorial

### Coordinación con ecosystem:
- Análisis base con `analizador-arquitectura`
- Optimización de performance con `performance-analyzer`
- Seguridad editorial con `security-guardian`
- Testing integral con `test-architect`
- Optimización de DB con `database-optimizer`

### Entregables esperados:
- Backend APIs específicamente diseñadas para funcionalidades editoriales
- Sistema de procesamiento optimizado que preserve calidad
- Integración perfecta entre interfaces editoriales y servicios backend
- Configuración Docker optimizada para operaciones editoriales
- Testing comprehensivo de toda la pipeline editorial

Crea una integración donde el módulo editorial tenga acceso a un backend robusto y optimizado que soporte todas las operaciones editoriales sin comprometer la calidad del contenido ni las configuraciones del usuario.
