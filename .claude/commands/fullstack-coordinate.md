## Tu Tarea

Coordina los agentes `desarrollador-fullstack-backend` y `desarrollador-frontend-ux` para crear experiencias fullstack perfectamente integradas.

**Tipo de coordinación:** ${ARGUMENTS:-integration}

### Instrucciones específicas:

**Para `frontend-backend`:** Integración completa entre sistemas frontend y backend
**Para `api-design`:** Diseño de APIs optimizadas específicamente para componentes frontend
**Para `integration`:** Optimización de comunicación y flujo de datos frontend-backend

### Objetivos de coordinación:

1. **Perfect Integration**: Frontend y backend trabajando como un sistema unificado
2. **Optimized APIs**: Endpoints diseñados específicamente para componentes UI
3. **Real-time Communication**: WebSockets, SSE, y comunicación bidireccional
4. **Performance Optimization**: Reducir latencia y optimizar transferencia de datos
5. **User Experience**: APIs que soporten experiencias de usuario fluidas

### Áreas de coordinación:
- Diseño de contratos API que optimicen componentes frontend
- Implementación de streaming para respuestas de Claude AI en tiempo real
- Optimización de payloads y serialización de datos
- Sincronización de estados entre frontend y backend
- Manejo de errores coherente en toda la aplicación
- Caching strategies que beneficien tanto frontend como backend

### Flujo de coordinación:

1. **Backend Development**: APIs robustas con `desarrollador-fullstack-backend`
2. **Frontend Integration**: Componentes optimizados con `desarrollador-frontend-ux`
3. **Communication Optimization**: Protocolos y formatos de datos optimizados
4. **Testing Integration**: Validación end-to-end de la integración
5. **Performance Validation**: Verificación de performance fullstack

### Coordinación obligatoria:
- Análisis arquitectónico base con `analizador-arquitectura`
- Validación de performance con `performance-analyzer`
- Verificación de seguridad con `security-guardian`
- Testing integral con `test-architect`

Crea una experiencia fullstack donde frontend y backend trabajen en perfecta armonía, proporcionando usuarios experiencias fluidas y desarrolladores APIs intuitivas y optimizadas.
