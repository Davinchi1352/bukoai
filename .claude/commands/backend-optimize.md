## Tu Tarea

Usa el agente `desarrollador-fullstack-backend` para optimizar sistemas backend existentes.

**Tipo de optimización:** ${ARGUMENTS:-performance}

### Instrucciones específicas:

**Para `performance`:** Optimiza rendimiento backend manteniendo calidad de respuestas
**Para `scaling`:** Prepara backend para escalamiento horizontal sin degradar servicio
**Para `quality`:** Optimizaciones técnicas que preserven 100% la calidad de contenido de libros

### Principios de optimización:

1. **Quality Preservation**: NUNCA comprometer calidad de libros generados
2. **User Configuration Sanctity**: Respetar absolutamente todas las configuraciones de usuario
3. **Token Optimization**: Optimizar uso de tokens SIN afectar calidad de contenido
4. **Intelligent Caching**: Cache solo metadata, NUNCA contenido principal de libros
5. **Performance vs Quality**: Priorizar calidad sobre velocidad cuando sea necesario

### Áreas de optimización:
- Optimización de consultas SQL manteniendo integridad de datos
- Mejora de APIs sin cambiar contratos existentes
- Optimización de integración Claude AI preservando calidad
- Caching inteligente que no afecte contenido de libros
- Escalabilidad horizontal sin pérdida de funcionalidades

### Coordinación obligatoria:
- Análisis base con `analizador-arquitectura`
- Validación de performance con `performance-analyzer`
- Optimización de DB con `database-optimizer`
- Verificación de seguridad con `security-guardian`

Optimiza el backend manteniendo excelencia técnica y preservando absolutamente la calidad del contenido y todas las configuraciones de usuario.
