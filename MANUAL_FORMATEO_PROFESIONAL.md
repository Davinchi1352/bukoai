## 🎯 **Introducción**

### ¿Qué es el Formateo Profesional?

El sistema de Formateo Profesional de Buko AI transforma tu manuscrito en un ebook con calidad editorial, optimizado para las principales plataformas de distribución digital como Amazon Kindle, Apple Books, Google Play Books y más.

### Beneficios Principales

✅ **Calidad Editorial**: Formato profesional que cumple estándares de la industria  
✅ **Multi-plataforma**: Optimización específica para cada tienda digital  
✅ **Automatización**: Proceso rápido sin necesidad de conocimientos técnicos  
✅ **Vista Previa**: Visualiza cambios en tiempo real antes de generar  
✅ **Puntuación de Calidad**: Indicador que te guía hacia el mejor resultado

---

## ✔️ **Requisitos Previos**

Antes de usar el formateo profesional, asegúrate de:

1. **Tu libro debe estar COMPLETADO**
   - Estado: "COMPLETED" en el sistema
   - Con todo el contenido generado

2. **Debes ser el propietario del libro**
   - Solo puedes formatear tus propios libros

3. **El libro debe tener contenido**
   - No se puede formatear un libro vacío

> **💡 Tip**: Si tu libro aún no está completado, espera a que termine la generación antes de acceder al formateo.

## 🚪 **Acceso al Formateo Profesional**

### Método 1: Desde la Vista del Libro

1. Ve a **"Mis Libros"** en el menú principal
2. Haz clic en el libro que deseas formatear
3. En la página del libro, busca el botón **"Formateo Profesional"**
4. Haz clic para acceder al editor de formateo

### Método 2: URL Directa

Accede directamente usando:
```
http://localhost:5001/books/book/[ID_DEL_LIBRO]/formatting-viewer
```

Reemplaza `[ID_DEL_LIBRO]` con el número de tu libro.

## 📝 **Opciones de Formato**

### Pestaña "Formato"

#### **Estructura del Libro**

Marca las secciones que deseas incluir:

| Elemento | Descripción | Recomendación |
|----------|-------------|---------------|
| **✅ Página de Portada** | Primera impresión visual | Siempre incluir |
| **✅ Página de Título** | Título y autor formal | Siempre incluir |
| **✅ Página de Derechos** | Copyright y avisos legales | Esencial para comercial |
| **✅ Tabla de Contenidos** | Navegación por capítulos | Altamente recomendado |
| **☐ Dedicatoria** | Dedicatoria personal | Opcional |
| **☐ Agradecimientos** | Reconocimientos | Opcional |
| **☐ Prólogo** | Introducción por otro autor | Si aplica |
| **☐ Epílogo** | Reflexión final | Si aplica |
| **✅ Acerca del Autor** | Tu biografía | Recomendado |
| **☐ Índice Temático** | Para libros técnicos | Según el género |

#### **Tipografía**

##### **Familia de Fuente**
- **Crimson Pro**: Elegante, ideal para ficción
- **Times New Roman**: Clásica, universal
- **Georgia**: Legible en pantallas
- **Palatino**: Sofisticada, para literatura
- **Book Antiqua**: Tradicional, libros impresos
- **Inter**: Moderna, sin serifas
- **Helvetica**: Limpia, técnica

##### **Tamaño de Fuente (9-16pt)**
- **9-10pt**: Máximo contenido por página
- **11-12pt**: Balance ideal (recomendado)
- **13-14pt**: Mayor legibilidad
- **15-16pt**: Accesibilidad visual

##### **Espaciado de Línea (1.0-2.5)**
- **1.0**: Compacto, más contenido
- **1.5**: Estándar (recomendado)
- **2.0**: Aireado, fácil lectura
- **2.5**: Máxima claridad

##### **Espaciado de Párrafo (0-12pt)**
- **0pt**: Sin espacio adicional
- **6pt**: Separación sutil (recomendado)
- **12pt**: Separación clara

#### **Características Comerciales**

##### **ISBN (Opcional)**
- Formato: `978-0-123456-78-9`
- Déjalo vacío si no tienes ISBN
- Útil para distribución profesional

##### **Tema Visual**
- **Clásico**: Diseño tradicional de libro
- **Moderno**: Estilo contemporáneo
- **Minimalista**: Limpio y simple
- **Académico**: Formal, para textos educativos

##### **Funciones Avanzadas**

| Función | Beneficio |
|---------|-----------|
| **✅ Navegación TOC** | Salto rápido a capítulos |
| **✅ Índice Automático** | Genera índice de términos |
| **✅ Marcadores** | Lectores pueden marcar páginas |
| **✅ Búsqueda** | Buscar texto en el libro |
| **✅ Optimizar Tamaño** | Archivo más pequeño |

## 📊 **Indicadores de Calidad**

### Panel de Calidad Comercial

#### **Puntuación General (0-100)**

El sistema evalúa tu configuración y asigna una puntuación:

| Rango | Color | Significado | Acción Recomendada |
|-------|-------|-------------|-------------------|
| **90-100** | 🟢 Verde | Excelente | Listo para publicar |
| **75-89** | 🔵 Azul | Bueno | Revisa sugerencias menores |
| **60-74** | 🟡 Amarillo | Aceptable | Mejora configuración |
| **0-59** | 🔴 Rojo | Necesita trabajo | Activa más opciones |

#### **Desglose por Categorías**

1. **Estructura (25 pts)**
   - Páginas esenciales presentes
   - Organización lógica
   - Elementos de navegación

2. **Formato (25 pts)**
   - Tipografía adecuada
   - Espaciado correcto
   - Legibilidad óptima

3. **Navegación (25 pts)**
   - Tabla de contenidos
   - Marcadores activos
   - Índices funcionales

4. **Comercial (25 pts)**
   - Optimización de archivo
   - Metadatos completos
   - Compatibilidad de plataforma

#### **Cómo Mejorar tu Puntuación**

Para alcanzar 90+ puntos:

1. ✅ Activa todas las páginas principales (portada, título, derechos, TOC)
2. ✅ Usa tamaño de fuente 11pt o mayor
3. ✅ Establece espaciado de línea de 1.4 o más
4. ✅ Habilita navegación TOC y marcadores
5. ✅ Activa optimización de tamaño
6. ✅ Incluye información del autor
7. ✅ Selecciona una plataforma específica (no universal)

## 🚀 **Generación del Formato Final**

### Proceso Paso a Paso

#### **1. Revisa tu Configuración**
- Verifica que la puntuación sea 75+ (idealmente 90+)
- Confirma la plataforma seleccionada
- Revisa la vista previa una última vez

#### **2. Haz Clic en "Generar Formato"**
- Botón azul con ícono de varita mágica
- Ubicado en el panel derecho inferior

#### **3. Espera el Procesamiento**
- Aparecerá: "Generando formato profesional..."
- Tiempo estimado: 10-30 segundos
- No cierres la página durante este proceso

#### **4. Confirmación de Éxito**
- Mensaje verde: "¡Formato profesional generado exitosamente!"
- Redirección automática en 2 segundos

#### **5. Descarga tu Libro**
- Serás dirigido a la página del libro formateado
- Opciones de descarga disponibles:
  - 📄 **PDF**: Para impresión o lectura en PC
  - 📱 **EPUB**: Para e-readers y tablets
  - 📘 **MOBI**: Para Kindle (si seleccionaste Amazon)
  - 📝 **DOCX**: Para edición adicional

### Estados del Proceso

| Estado | Mensaje | Significado |
|--------|---------|-------------|
| **ℹ️ Info** | "Generando formato..." | Procesamiento en curso |
| **✅ Éxito** | "Formato generado exitosamente" | Completado sin errores |
| **⚠️ Advertencia** | "Formato generado con advertencias" | Revisar sugerencias |
| **❌ Error** | "Error al generar formato" | Intentar de nuevo |

## 🔧 **Solución de Problemas**

### Problemas Comunes y Soluciones

#### **"El libro debe estar completado"**
- **Causa**: El libro aún se está generando
- **Solución**: Espera a que termine y el estado sea "COMPLETED"

#### **"No tienes permiso para formatear este libro"**
- **Causa**: No eres el propietario del libro
- **Solución**: Solo puedes formatear tus propios libros

#### **"El libro no tiene contenido"**
- **Causa**: Error en la generación del contenido
- **Solución**: Regenera el libro desde el panel principal

#### **La vista previa no carga**
- **Causa**: Contenido muy extenso o conexión lenta
- **Solución**: Espera 5-10 segundos o actualiza la página

#### **Puntuación de calidad muy baja**
- **Causa**: Pocas opciones activadas
- **Solución**: Activa más elementos en las pestañas Formato y Estilo

#### **Error al generar formato**
- **Causa**: Problema temporal del servidor
- **Solución**: 
  1. Espera 1 minuto
  2. Actualiza la página
  3. Intenta de nuevo
  4. Si persiste, contacta soporte

#### **El formato generado no se ve bien**
- **Causa**: Configuración inadecuada para el contenido
- **Solución**: 
  1. Vuelve al formateo profesional
  2. Ajusta tipografía y espaciado
  3. Revisa en vista previa
  4. Genera de nuevo

## ❓ **Preguntas Frecuentes**

### **1. ¿Puedo formatear el mismo libro varias veces?**
✅ Sí, puedes reformatear cuantas veces necesites sin costo adicional.

### **2. ¿Se pierde el formato anterior al generar uno nuevo?**
✅ No, cada formato se guarda por separado. Puedes tener múltiples versiones.

### **3. ¿Cuánto tiempo tarda el formateo?**
⏱️ Entre 10-30 segundos para libros normales. Libros muy extensos pueden tardar hasta 1 minuto.

### **4. ¿Puedo editar el formato después de generarlo?**
📝 El DOCX generado es editable. Los otros formatos son finales.

### **5. ¿Qué plataforma debo elegir si quiero vender en varias tiendas?**
🌍 Selecciona "Universal" para máxima compatibilidad.

### **6. ¿El ISBN es obligatorio?**
❌ No, es completamente opcional. Muchos autores publican sin ISBN.

### **7. ¿Qué significa cada indicador de calidad?**
📊 Ver sección [Indicadores de Calidad](#indicadores-de-calidad) para detalles completos.

### **8. ¿Puedo cambiar el formato después de publicar?**
✅ Sí, pero deberás actualizar el archivo en la plataforma de publicación.

### **9. ¿Por qué mi libro tiene menos páginas después del formateo?**
📄 El formateo profesional optimiza el uso del espacio. El contenido es el mismo.

### **10. ¿Qué formato debo descargar para Amazon Kindle?**
📱 Amazon acepta EPUB, pero puedes usar nuestro preset "Amazon KDP" para optimización.

## 💡 **Consejos de Experto**

### Para Máxima Calidad

1. **Siempre incluye**:
   - Página de título
   - Página de derechos
   - Tabla de contenidos
   - Información del autor

2. **Tipografía ideal**:
   - Ficción: Crimson Pro o Georgia, 12pt, espaciado 1.5
   - No ficción: Times New Roman o Inter, 11pt, espaciado 1.5
   - Académico: Palatino o Book Antiqua, 12pt, espaciado 2.0

3. **Por género**:
   - **Novelas**: Activa capitulares y tipografía profesional
   - **Técnicos**: Prioriza índices y navegación
   - **Infantiles**: Fuente más grande (14pt+) y mayor espaciado
   - **Poesía**: Minimalista, sin elementos extra

4. **Antes de publicar**:
   - Genera una versión "Universal" de respaldo
   - Revisa la vista previa en diferentes tamaños
   - Verifica que la puntuación sea 85+
   - Descarga todos los formatos disponibles
